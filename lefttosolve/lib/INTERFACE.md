# Shared interface (lead-defined; do not change without telling the lead)

Goal: close two open lefttosolve.com problems that both need a FAST, VERIFIED prime sieve
the Lean kernel can evaluate with `decide +kernel` (native_decide is forbidden).

  OeisA92243.conjecture1  : ∃ n > 250000, a n > 0        (witness n = 261150, p_n = 3666581)
  OeisA100475.conjecture  : disproof; needs π(10^5) < 10^4, π(10^6) < 10^5, π(10^7) < 10^6

## The contract
A sieve agent delivers, in its own namespace `OMA.SieveA` / `OMA.SieveB`:

    def primeList (N : ℕ) : List ℕ                      -- computable, kernel-friendly
    theorem primeList_eq (N : ℕ) :
        primeList N = (List.range (N + 1)).filter (fun m => decide m.Prime)

and benchmarks: kernel time of
    example : (OMA.SieveX.primeList 3666581).length = 261151 := by decide +kernel
(π(3666581) = 261151, i.e. Nat.nth Nat.Prime 261150 = 3666581)
and if possible the same for 10^7 (π = 664579). A different but equivalent spec is fine
(e.g. a count function with `count_eq : primeCount N = Nat.count Nat.Prime (N+1)`, or a
Bool-array membership function), as long as you document it here under your heading.

A reduction agent proves everything else against the SLOW stand-in
    def primeListSpec (N : ℕ) : List ℕ := (List.range (N + 1)).filter (fun m => decide m.Prime)
and leaves exactly the kernel computations as the final step, so a sieve can be swapped in by
rewriting with `primeList_eq`.

## File-level rules (the site's checker; the final submission is ONE file)
- Starts with the given `import FormalConjectures.OEIS.«N»` line; Mathlib imports may follow.
- Only: theorem lemma def abbrev structure inductive instance open namespace section end
  variable universe, `set_option <maxHeartbeats|maxRecDepth|synthInstance.maxHeartbeats|
  synthInstance.maxSize> <n> in`, @[simp] / @[local simp].
- Forbidden: sorry admit axiom native_decide `decide := true` unsafe partial implemented_by
  extern macro syntax elab notation initialize run_cmd #-commands attribute opaque, and NO
  double-quote character anywhere. `decide +kernel` is allowed.
- No `partial`, so use structural recursion (fuel arguments) for kernel evaluation;
  well-founded recursion does not reduce well in the kernel.
- Whole file must check in < 30 min, < 7 GB (aim for < 10 min).
- Only axioms propext, Classical.choice, Quot.sound.
